Multi-Screen Media player for Worship

An open-source multimedia player built for seamless presentations, high-performance audio and video, native image rendering.

Download for Windows (x64) View Source Code

Key Features

Multi-Screen Support

No more minimizing, maximizing, or dragging windows to extended displays. Features a dedicated, selectable control interface and an independent projection output.

Seamless Transitions

Built-in crossfading and smooth visual transitions powered by LibVLCSharp.

Library Integration

Quick access to hymns, favorites, custom local folders and removable USB drives.

Save Playlists

Quick access to saved playlists to optimize usage during your worship services.
